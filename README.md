# Soul

### Unreal Engine 5.6 기반의 C++ 중심 소울라이크 3인칭 액션 RPG 프로젝트입니다.
### 실제 소울라이크 게임의 전투 구조를 참고하되, 개인 프로젝트 범위에 맞게 시스템을 재구성하는 것을 목표로 설계되었습니다.
### 스태미나 기반 전투, 무기 전환, 캐릭터 성장, AI 전투를 핵심으로 하는 싱글 플레이 경험을 목표로 합니다.

## 프로젝트 개요
- **장르**: 3인칭 액션 RPG/소울라이크 스타일 전투를 지향하는 캐릭터 중심 게임 (근접/원거리 무기 전환, 회피, 스태미나 기반 전투 구조)
- **목표**: 캐릭터 성장/장비/전투를 중심으로 한 싱글 플레이 경험 구현 (스탯 투자, 인벤토리, 세이브 데이터 기반 진행)
- **플랫폼**: Unreal Engine 프로젝트 구조 기준(에디터/PC 개발 환경)

## 프로젝트 기간
- 2025.12 ~ 2026.01

## 프로젝트 목적
- Unreal Engine C++ 기반 게임플레이 아키텍처 설계 경험
- 소울라이크 전투 구조(스태미나/회피/콤보) 구현
- 데이터 중심 AI 및 세이브 시스템 설계 연습

## 아키텍처 개요
-본 프로젝트는 1인 개발이지만, 실제 팀 개발 환경을 가정하여 시스템 간 책임 분리와 확장성을 중심으로 설계되었습니다.
-각 시스템은 명확한 역할을 가지며, 하나의 시스템 수정이 다른 시스템에 영향을 최소화하도록 구성되어 있습니다.

## 설계 제약 조건
- 게임플레이 로직은 애니메이션 프레임 데이터에 의존하지 않도록 설계
- 전투 상태 정보는 AI 및 UI 시스템에서 조회 가능해야 함
- 세이브 데이터의 소유권을 중앙에서 관리하여 상태 불일치 발생을 방지

## 주요 기능 / 시스템
- **캐릭터 시스템** : 이동/질주/공격/회피/사다리 이동, 무기 전환(검/총/빈손), 자동 에이밍/조준, 공격 콤보 로직 등
- **스탯/성장** : STR/DEX/VIT/END 스탯, 파생 능력치(HP/스태미나/피해량), 레벨/소울 투자 및 세이브 기능
- **인벤토리** : 슬롯/퀵슬롯, 아이템 획득/사용, 포션/강화석 등 소모 아이템 기반 관리 및 저장/로드 기능
- **전투 시스템** : 근접/원거리 공격, 공격 판정, 피해 처리, 피격 반응, 사망 처리 등 전투 흐름 포함
- **AI/적 시스템** : 적 타입(로머/매복/보스), 인지/추적/순찰/공격 범위 설정, 비헤이비어 트리 기반 서비스/태스크 구성
- **인터랙션** : 문/상자/사다리 등 상호작용 오브젝트 및 인터페이스 구조
- **UI 시스템** : HUD, 크로스헤어, 상호작용 프롬프트, 인벤토리, 상태창, 게임오버/클리어, 일시정지 UI 위젯 구성
- **세이브/설정** : 게임 진행, 캐릭터 스탯, 인벤토리, 게임 설정 저장 구조

## 시스템 책임 분리

### 캐릭터 / 전투 시스템
담당 역할:
- 플레이어 입력을 기반으로 한 상태 전이 관리 (Idle / Attack / Dodge / Hit)
- 스태미나 소모 및 행동 가능 여부 판단

담당하지 않는 역할:
- 공격 타이밍 결정
- 히트 판정 시점 처리  
(해당 부분은 애니메이션 시스템에서 처리)

### 애니메이션 시스템
담당 역할:
- 공격 콤보 입력 가능 타이밍 제어
- 애니메이션 타이밍에 맞춘 히트 판정 트리거

분리 목적:
- 애니메이션 수정이 게임플레이 코드 수정으로 이어지지 않도록 구조 분리

## 캐릭터 컨트롤
- **이동/시점** : 이동 및 시점 회전 입력 처리, 스프린트/스태미나 관리
- **전투 입력** : 공격/회피/무기 전환(검/총/빈손), 조준/사격, 콤보 진행 관리
- **상호작용** : 문/상자/사다리 등 인터랙션 대상 접근 및 상호작용 처리

## 전투 / AI
- **적 타입** : 근접/원거리/보스 등 개별 클래스 기반 구현
- **AI 로직** : 시야/어그로/공격 범위와 순찰 방식(고정/랜덤)을 데이터 에셋으로 설정하고, BT 서비스/태스크로 타깃 추적/공격 실행
- **피해 처리** : 적/플레이어 모두 피해, 피격 반응, 사망, UI 연계(HP 바/피해 텍스트) 포함

## 레벨 디자인
- **레벨 요소** : 순찰 포인트 기반 이동, 랜덤/고정 순찰 모드, 상호작용 오브젝트(문/상자/사다리)로 탐험/진행 설계 가능
- **레벨 자산** : 실제 맵/레벨/환경 에셋은 `Content/` 폴더에 위치하는 Unreal 프로젝트 구조를 따릅니다.

## UI / 사운드
- **UI** : HUD, 크로스헤어, 인벤토리, 상태창, 일시정지, 게임 오버/클리어 위젯 제공
- **사운드** : 배경 음악 재생/정지, 사운드 믹스/클래스 구성 및 저장된 설정 로드 지원

## 프로젝트 구조
- `Config/` : Unreal 설정 파일
- `Content/` : 레벨/메시/애니메이션/머티리얼 등 에셋
- `Source/` : C++ 코드
    - `Source/Soul/Character` : 플레이어 캐릭터, 스탯, 인벤토리, 무기 로직
    - `Source/Soul/Enemy` : 적 캐릭터 및 AI 로직
    - `Source/Soul/Interact` : 인터랙션 가능한 오브젝트
    - `Source/Soul/Game` : 게임 모드/플레이어 컨트롤러/세이브
    - `Source/Soul/UI` : HUD 및 각종 UI 위젯
 
## 팀 개발을 가정했을 때 발생 가능한 문제점
- 애니메이션 노티파이 이름 규칙이 통일되지 않을 경우 로직 오류 가능성 존재  
→ 향후 개선 방향: 노티파이 타입을 enum 기반으로 관리하여 일관성 확보

- 전투 상태 enum 확장 시 조건 분기 증가 가능성  
→ 향후 개선 방향: 상태별 처리 클래스를 분리하여 복잡도 감소

## C++ / Blueprint 사용 기준
- 캐릭터, 전투, AI, 인벤토리, 세이브 등 핵심 게임플레이 로직은 C++ 기반으로 구현
- Blueprint는 데이터 설정, UI 위젯, 에디터 확장이 필요한 부분에 한해 사용
- 이를 통해 기획/아트 작업자가 코드 수정 없이도 반복 작업이 가능하도록 구성
